# 🚲 Bike Sales Analysis & Dashboard

## 📌 Overview

This project focuses on cleaning, analyzing, and visualizing a bike sales dataset using Microsoft Excel.

The original dataset contained approximately 1,000 customer records with inconsistent formatting, duplicate records, and values that were not easy to interpret. I cleaned and transformed the raw data, created additional analytical fields, and built an interactive dashboard to identify patterns in customer bike purchasing behavior.

## 🎯 Project Objective

The main objective of this project was to transform raw customer data into a clean and interactive dashboard that can be used to understand which customer characteristics are associated with bike purchases.

The analysis focuses on factors such as:

- Income
- Gender
- Age
- Marital Status
- Education
- Occupation
- Home Ownership
- Number of Cars
- Commute Distance
- Region
- Bike Purchase Status

## 🧹 Data Cleaning & Preparation

The raw dataset was cleaned and prepared before performing the analysis.

Key steps included:

- Removed duplicate records
- Standardized inconsistent values
- Improved the readability of categorical variables
- Converted abbreviated values into descriptive labels
  - `M` → `Male`
  - `F` → `Female`
  - `M` → `Married`
  - `S` → `Single`
- Added an **Age Bracket** column to categorize customers
- Organized income and demographic information
- Prepared the cleaned dataset for Pivot Table analysis

## 📊 Dashboard

An interactive **Bike Sales Dashboard** was created in Excel using Pivot Tables, Pivot Charts, and slicers.

The dashboard provides insights into:

### 💰 Average Income
Compares the average income of customers who purchased a bike with those who did not, broken down by gender.

### 🚗 Customer Commute
Shows the relationship between commute distance and bike purchasing behavior.

### 👥 Age Brackets
Analyzes bike purchases across different customer age groups.

### 🌍 Customer Demographics
Allows users to filter the dashboard based on:

- Marital Status
- Region
- Education
- Gender
- Age Bracket
- Bike Purchase Status
